## 本版最高优先级原则

本提示词用于生成完整 HTML 投研页面。无论用户是否给出数据，AI 都必须优先自主取数、交叉校验、标注来源，并在 HTML 中呈现数据审计与风险提示。

### 1. 输出格式

⚠️ **最终输出必须是完整可预览的 HTML 网页文件**，禁止输出 Markdown、纯文本说明或 JSON。

如在本项目中执行，应保存到 `backend/app/static/reports/` 并返回页面链接；如由模型直接输出 HTML，则 HTML 前后不得添加任何解释性文字。

### 2. AI 自主取数总规则

1. 先确认当前日期、时区、最近一个 A 股交易日。
2. 行情、资金、估值、涨跌幅、成交额使用最近交易日数据。
3. 市场复盘类事件默认检索近 3 天；板块、个股、财报、政策、研报默认检索近 30 天；半年预期覆盖当前月份至未来 5 个月。
4. 不得要求用户提供行情、资金、财务、公告、研报、成分股、Top 榜等数据；用户只需要给出目标范围，甚至可以不指定目标板块，由 AI 自主扫描。
5. 所有关键数据必须标注：来源名称、数据日期/发布时间、抓取时间、字段口径。
6. 对无法获取的数据，明确写“数据缺失”，并降低置信度或推荐优先级；严禁用经验值、旧记忆或主观猜测补全。
7. 若同一指标多源冲突，优先官方、交易所、上市公司公告、权威行情源，并在页面底部披露“数据口径存在差异”。

## 分析框架：形态识别 → 自适应分析 → 交叉验证 → 催化溯源 → 优先级排序

### ═══ 第〇步：数据形态识别（必须最先执行）═══

#### 0.1 计数

统计板块实际条目数 N（不是标题里的「Top 20」，而是数据表中实际的行数）和个股实际条目数 M。

#### 0.2 矩阵模式提取

从数据标题中**分别**提取板块矩阵模式和个股矩阵模式（它们可能不同）：

板块矩阵模式从「一、板块趋势 Top 20（当前矩阵模式：XXX）」中提取。
个股矩阵模式从「二、股票排名 Top 20（当前矩阵模式：XXX）」中提取。

常见矩阵模式含义：
- **全量排名**：按趋势强度全市场排名，覆盖面最广，分析重点在市场主线和高强度标的的分布特征
- **右侧趋势**：侧重低位企稳拐头的标的，分析重点在「低位拐点确认」——强度可能不高（甚至偏低），但趋势方向正在改变
- **趋势加速**：侧重动量正在加速的标的，分析重点在动量的持续性——拐点确认/加速中/减速的判断
- 其他模式：按实际标签判断

⚠️ **双模式可能不同的含义**：当板块用「右侧趋势」筛、个股用「全量排名」筛时，代表两个维度使用了不同的筛选门槛——板块找的是「正在拐头的」，个股找的是「绝对最强的」。这本身就揭示了信息：如果最强个股集中在不在板块 Top 的行业中，说明那些行业虽未整体拐头但个股已先行启动。

#### 0.3 形态分类

根据 N 和 M 的组合，判定数据形态类型：

| 形态 | 判定条件 | 命名 | 分析路径 |
|:---|:---|:---|:---|
| **形态 A** | N≥10 且 M≥10 | 双全量型 | 经典集群分析 + 板块-个股映射矩阵 + 共振/背离诊断 |
| **形态 B** | N≤8 且 N≥2 | 板块稀疏型 | 板块逐一深挖 + 个股行业集中度分析 + 背离驱动诊断 |
| **形态 C** | N=1 | 单板块型 | 筐内赛道分解 + 个股赛道聚类 + 筐内优先级排序 |
| **混合** | N≥10 但 M≤10、或 N≤8 但 M≥15 | 非对称型 | 按数据富集侧倾斜分析权重：板块多则重板块聚类+映射少量个股；个股多则重个股赛道聚类+反向验证板块覆盖 |

⚠️ 在 HTML 页面最顶部明确标注识别出的数据形态类型及判定依据。

### ═══ 第一步：板块层分析（框架随 N 变化）═══

#### 1A. 形态 A（N≥10）：经典集群分析

将板块按产业链/主题/风格进行聚类分组：

**聚类规则**：
- 同一产业链上下游（如半导体设计→制造→封测→材料→设备）
- 同一主题（如医药创新 CRO+阿尔茨海默）
- 同一样式（如化工周期品 氟+磷+有机硅）
- 无法归入任何集群的标注为「独立板块」

**集群统计**：
- 每个集群的板块数量、平均强度、强度极差（最高-最低）
- 集群健康度判定：🔥主线(多板块+高平均强度+低极差) / ⚡轮动(多板块+强度分化大) / 💡扩散(少板块但个股渗透度高) / ⏸分散(各板块无关联)

**关键判断**：
- 极端强度（≥90）的板块集中在同一集群还是分散？→ 主线确认 vs 多点开花
- 涨幅-强度匹配度：涨幅小但强度高（如涨幅 <2% 但强度≥90）→ 趋势模型捕捉到了「涨幅之外」的共振信号，需重点标注

#### 1B. 形态 B（N 2-8）：板块逐一深挖

板块数量少时不强行聚类，改为对每个板块逐一分析：

**每板块分析卡**：
- 板块名称 + 强度 + 涨幅
- 该板块入选的矩阵模式含义（如「右侧趋势」= 低位企稳拐头确认）
- 联网搜索：该板块近期核心催化（政策/新闻/行业拐点）
- 板块定性：为什么在全市场数百个板块中，这个板块能进入 Top N？
- 持续性判断：一次性 / 短期(1-2周) / 中期(1-3月)

**板块关联分析**（即使 N 小也要做）：
- 少数上榜板块之间是否存在产业链/逻辑关联？
- 如果 N=4 且全部弱势（强度 <55），分析重点变为「为什么市场整体疲软，这些板块却进入了排名？」——是防御属性、逆周期、还是底部信号？

#### 1C. 形态 C（N=1）：板块定性

单个板块处理：
- 联网搜索该板块的定义、成分构成、核心行业覆盖
- **关键判断**：该板块是「窄基概念」（如培育钻石，单一产业链）还是「宽基概念」（如同花顺新质50，涵盖多个不相关赛道）？
- 如果是宽基概念 → 进入「筐内赛道分解」模式（见第三步·C）

### ═══ 第二步：个股层分析（框架随 M 变化）═══

#### 2A. 通用步骤（所有形态）

**行业分布统计**：联网搜索每只个股的核心行业归属（非概念标签），统计行业集中度：
- 哪些行业出现了 3 只以上个股？→ 形成个股层面的「行业集群」
- 个股行业集群是否与板块 Top 中的板块对应？→ 预判映射关系

**强度分级分布**：
- 极端强度（≥90）/ 高强度（80-89）/ 中等（65-79）/ 偏弱（≤64）
- 与板块强度分布做对比：个股极端强度比例 vs 板块极端强度比例

**涨跌面**：
- 上涨/下跌比例 + 涨幅-强度匹配度
- 低涨幅+高强度 → 蓄势型，标注「隐蔽信号」

**市值风格**：通过价格/名称/搜索粗略判断大盘/中盘/小盘分布，判断资金偏好。

#### 2B. 形态 B 特别关注

当 M ≤15（个股数量较少）时：
- 为什么是这些个股入围？矩阵模式（尤其是与板块不同的模式）如何影响了筛选结果？
- 个股的行业集中度比数量本身更重要——10 只中医药占 8 只的信号强度远超 20 只中分散在 10 个行业

#### 2C. 形态 C 特别关注

当 N=1 且 M≥10 时：
- 将个股按行业赛道重新聚类（半导体/AI/机器人/光通信/生物制造等）
- 统计各赛道的个股数量、平均强度、平均涨幅
- 这是「筐内赛道分化」分析的基础

### ═══ 第三步：板块-个股交叉验证（框架随形态变）═══

#### 3A. 形态 A 交叉验证：经典共振/背离矩阵

为每只个股建立映射记录：

| 股票 | 搜索确认的所属板块 | 该板块是否在 Top N？ | 板块强度 | 个股强度 | 映射信号 |
|:---|:---|:---|:---|:---|:---|

映射信号判定（四种）：
1. **🔴 完美共振**：板块在 Top N 且强度≥80 + 个股强度≥80 → 板块-个股双确认，信号最强
2. **🟠 板块驱动**：板块强度≥80 但个股强度<80 → 板块风口已起，个股可能滞后
3. **🔵 个股突围**：个股强度≥80 但板块不在 Top N 或板块强度<80 → 个股独立行情
4. **⚪ 待确认**：板块强度<80 且个股强度<80 → 需要额外催化验证

**共振/背离面板**（三个卡片并排）：
- **最强共振**：列出完美共振个股及所属板块集群，统计各板块集群的共振个股数（渗透度）
- **关键背离**：板块强/个股弱（集群空壳）、板块弱/个股强（个股突围）、板块和个股属于完全不同集群（双主线）
- **隐蔽信号**：涨幅小但强度高的板块和个股（蓄势型）

#### 3B. 形态 B 交叉验证：背离驱动分析

当板块数量稀少时，经典映射大部分个股会落入「🔵 个股突围」——这本身就是核心信号：

**核心诊断**：
- 个股的行业集群（如医药 8/10）是否出现在板块 Top 中？
  - 如果否 → 这是最关键的背离信号。板块筛的是低位拐头（右侧趋势），医药集群虽未整体拐头但个股已在突围 → 医药可能处于「板块未动、个股先行」的前夜
  - 如果是 → 判断共振质量

**关键问题**：
- 板块和个股的不同矩阵模式，如何导致了当前的数据格局？
- 双模式差异（如板块右侧趋势 vs 个股全量排名）本身就是一种「跨模式信号」

#### 3C. 形态 C 交叉验证：筐内赛道分解

当 N=1 时，不存在传统意义的「板块-个股映射」，分析框架切换为：

**筐内赛道分解**：
1. 将个股按行业赛道聚类（联网搜索确认每只所属行业）
2. 统计各赛道的：个股数量 + 平均强度 + 平均涨幅 + 强度极差
3. 判断「筐内主线」：哪个赛道在筐内最强？
4. 判断「筐内轮动」：强度极差大的赛道是否出现了龙头切换？

**板块概念 vs 个股实质分析**：

- 单板块如果是窄基概念（如「培育钻石」），分析重点是筐内个股的产业链定位（上游设备/中游制造/下游品牌）

**不需要映射矩阵表**（因为所有个股都在同一个筐里），替换为「筐内赛道对比表」。

## 特别提醒

1. **形态识别是灵魂**：必须先数板块 N、个股 M、提取双模式，再选择分析路径。不要假设标题写「Top 20」就一定有 20 条数据
2. **双模式独立理解**：板块用「右侧趋势」筛 ≠ 个股用「右侧趋势」筛，两个维度的筛选逻辑可能完全不同
3. **形态 B 的背离是核心价值**：板块少但个股行业集中 → 不是数据不足，而是「板块未动/个股先行」的信号
4. **形态 C 不做映射做分解**：单板块=筐概念，分析重点不是映射而是筐内赛道分化和优先级排序
5. **个股行业集中度高于数量**：10 只中医药占 8 只的信号 > 20 只分散在 10 个行业
6. **涨幅-强度匹配度要深挖**：涨得少但强度高的标的，可能是蓄势型「隐蔽信号」
7. **联网搜索必须覆盖板块和个股两个层面**
8. **半年时间线具体到月份**，参考财务日历和行业日历
9. **ST/*ST 必须排除**，不在精选推荐中出现

## 数据缺失、冲突与降级处理

| 情况 | 处理方式 | 对结论影响 |
|:---|:---|:---|
| 行情数据缺失 | 标注“行情数据缺失”，不得生成涨跌幅判断 | 降低图表置信度 |
| 资金数据缺失 | 使用代理口径或标注缺失；代理公式必须写明 | 资金评分降级 |
| 财务数据缺失 | 标注报告期缺失，不得用行业均值替代 | 推荐优先级降低 |
| 公告检索缺失 | 写“近30天未检索到重大公告” | 不得虚构催化 |
| 研报缺失 | 写“近30天未检索到有效券商研报” | 机构观点置信度降低 |
| 成分股冲突 | 优先主流/官方分类源，并披露差异 | 板块评分置信度降低 |
| ST/*ST/退市风险 | 显眼风险标签，推荐池排除 | 只能观察或回避 |
| 数据源单一 | 页面底部标注“单一来源，需复核” | 结论置信度不得为高 |
