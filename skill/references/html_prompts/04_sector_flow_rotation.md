### 板块资金沉淀率公式

```text
板块资金沉淀率 = 区间板块主力净流入额 / 板块总流通市值 × 100%
```

若无法获取板块总口径，则用板块成分股逐一汇总，必须披露“成分股汇总代理口径”。

### 必须新增的持续性诊断

- 3D > 5D > 20D 且均为正：资金加速流入。
- 3D 正、20D 负：短线交易或一日游风险。
- 3D 负、20D 正：高位分歧，判断洗盘还是出货。
- 三周期均负且绝对值扩大：趋势性撤离。
- 资金流入但近期涨幅过大：警惕高潮期和拥挤撤退。

# 核心分析任务

请自主获取最新的板块资金沉淀率数据，完成以下九步分析流程：

## 第一步：沉淀率绝对值定级

对所有板块的沉淀率进行绝对值定级，判断基准如下：

| 沉淀率区间 | 资金信号 | 含义 |
|:---|:---|:---|
| > 10% | 🔥🔥🔥 极端抢筹 | 机构不计成本扫货，往往伴随行业重大转折或政策超级催化 |
| 5%-10% | 🔥🔥 显著流入 | 明确的机构加仓行为，需要查证催化逻辑 |
| 2%-5% | 🔥 温和关注 | 有资金试探但力度有限，需要观察持续性 |
| 0%-2% | 正常波动 | 无明显资金倾向 |
| -2% - 0% | 轻微流出 | 可能有少量获利了结，无需过度解读 |
| -10% - -2% | ❄️ 温和撤退 | 资金有序撤离，需要警惕趋势弱化 |
| -20% - -10% | ❄️❄️ 显著撤离 | 明确的主力减仓信号 |
| < -20% | ❄️❄️❄️ 恐慌出逃 | 资金大面积撤离，往往是系统性风险信号或板块逻辑遭颠覆 |

## 第二步：一日游 vs 趋势性判断

**如果数据只有单一周期**：通过沉淀率绝对值 + 板块基本面 + 催化逻辑综合判断：
- 沉淀率极高（>8%）且有重磅催化支撑 → 趋势性概率高
- 沉淀率中等（3-8%）且催化模糊 → 存在一日游风险
- 沉淀率低（<3%）且无实质催化 → 大概率一日游
- 注意对比板块的流通盘规模：小流通盘板块的高沉淀率可能是少数标的集中流入造成的假象

**如果数据包含多周期**：对比 3日/5日/10日/20日/60日 各周期沉淀率的变化趋势：
- 各周期全部正值且递增 → 趋势性建仓（最强信号）
- 短周期正值、长周期负值 → 短期博弈（一日游风险高）
- 短周期负值、长周期正值 → 高位分歧（需警惕撤离加速）
- 各周期全部负值且递减 → 趋势性撤离（最弱信号）
- 各周期正值但减速 → 资金边际减弱（顶背离信号）
- 各周期负值但收敛 → 资金边际改善（底背离信号）

## 第三步：资金流入板块的催化追溯

针对每一个资金流入 Top 板块，联网搜索以下方向：
1. **政策面**：近期是否有国务院/部委/地方政府出台该行业相关政策？政策力度如何（规划/方案/税收优惠/补贴/法规）？
2. **产业面**：行业是否有供需拐点信号（涨价/缺货/产能释放/新应用）？是否有技术突破或产品周期启动？
3. **财报面**：板块内龙头公司近期是否发布了超预期业绩/预增公告？
4. **事件面**：近期是否有行业大会/产品发布会/订单公告等催化事件？
5. **外围面对标**：国际同行业是否有重大事件（海外龙头大涨/政策变化/技术迭代）映射A股？

对每个板块给出催化确定性评级：★★★★★（多重催化共振）→ ★☆☆☆☆（无明显催化，警惕一日游）

## 第四步：资金流出板块的撤离诊断

针对每一个资金流出 Bottom 板块，联网搜索：
1. **逻辑崩塌**：板块的核心投资逻辑是否被证伪或弱化？（如政策转向/技术路线被替代/需求见顶）
2. **获利了结**：是否前期涨幅过大，资金有序兑现？（需查证该板块近1-3个月涨幅）
3. **高低切换**：是否为正常的板块轮动——资金从一个高估值赛道切换到低估值板块？
4. **利空冲击**：是否有突发利空（业绩暴雷/政策收紧/海外制裁/安全事故）？

对每个流出板块给出撤离性质判断：🔴 逻辑颠覆 / 🟡 获利了结 / 🟢 健康轮动 / ⚪ 临时扰动

## 第五步：板块轮动全景推演

综合分析 Top 和 Bottom 板块，推导当前市场的资金迁徙路径：

1. **从哪来**：流出板块主要集中在什么赛道？（如：AI算力链/新能源/消费/周期）→ 总结撤出方向
2. **到哪去**：流入板块主要集中在什么赛道？（如：内需消费/困境反转/政策驱动）→ 总结加仓方向
3. **为什么**：这种迁徙的逻辑是什么？（如：降息预期受益/政策纠偏/估值洼地/业绩确定性/防御切换）
4. **持续性**：这种迁徙是短期交易性还是中期趋势性？给出判断依据

## 第六步：重点板块深度拆解

从流入 Top 5 中挑出 3 个最值得关注的方向（沉淀率 + 催化确定性 + 产业前景综合最优），每个做深度分析：

对于每个重点板块：
- **产业链画像**：上游→中游→下游→配套，一句话概括各环节
- **核心逻辑**：本轮资金流入的根本原因（不超过3句话）
- **关键验证点**：未来1-2周需要观察什么数据/事件来证实或证伪当前逻辑
- **反面论证**：如果这个板块的判断错了，最可能的原因是什么
- **半年关键节点**：该板块未来6个月最重要的催化事件（按月份列出）

## 第七步：隐蔽信号挖掘

从数据中识别以下非直观信号：

1. **边缘板块异动**：排名靠后但沉淀率绝对值并不低的板块是否被忽视？
2. **反向信号**：流出板块中是否存在被错杀的优质赛道？（机构被迫减仓而非主动看空）
3. **时间差信号**：某些板块的沉淀率变化是否领先于基本面变化，构成先行指标？
4. **配对交易**：流入和流出板块之间是否存在对冲逻辑？（如：复苏链 vs 避险链）

## 数据缺失、冲突与降级处理

| 情况 | 处理方式 | 对结论影响 |
|:---|:---|:---|
| 行情数据缺失 | 标注“行情数据缺失”，不得生成涨跌幅判断 | 降低图表置信度 |
| 资金数据缺失 | 使用代理口径或标注缺失；代理公式必须写明 | 资金评分降级 |
| 财务数据缺失 | 标注报告期缺失，不得用行业均值替代 | 推荐优先级降低 |
| 公告检索缺失 | 写“近30天未检索到重大公告” | 不得虚构催化 |
| 研报缺失 | 写“近30天未检索到有效券商研报” | 机构观点置信度降低 |
| 成分股冲突 | 优先主流/官方分类源，并披露差异 | 板块评分置信度降低 |
| ST/*ST/退市风险 | 显眼风险标签，推荐池排除 | 只能观察或回避 |
| 数据源单一 | 页面底部标注“单一来源，需复核” | 结论置信度不得为高 |

## 最终输出自检清单
