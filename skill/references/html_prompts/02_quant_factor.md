> 说明：本文件参照 `docs/Prompt/FunctionPrompt.ipynb` 原始模板扩展而来，保留原模板的分析框架和 HTML 模块密度，并增强为 AI 自主取数、数据审计、多智能体交叉验证和缺失数据降级版本。

## 本版最高优先级原则

本提示词用于生成完整 HTML 投研页面。无论用户是否给出数据，AI 都必须优先自主取数、交叉校验、标注来源，并在 HTML 中呈现数据审计与风险提示。

### 1. 输出格式

⚠️ **最终输出必须是完整可预览的 HTML 网页文件**，禁止输出 Markdown、纯文本说明或 JSON。

如在本项目中执行，应保存到 `backend/app/static/reports/` 并返回页面链接；如由模型直接输出 HTML，则 HTML 前后不得添加任何解释性文字。

### 2. AI 自主取数总规则

1. 先确认当前日期、时区、最近一个 A 股交易日。
2. 行情、资金、估值、涨跌幅、成交额使用最近交易日数据。
3. 市场复盘类事件默认检索近 3 天；板块、个股、财报、政策、研报默认检索近 30 天；半年预期覆盖当前月份至未来 5 个月。
4. 不得要求用户提供行情、资金、财务、公告、研报、成分股、Top 榜等数据；用户只需要给出目标范围，甚至可以不指定目标板块，由 AI 自主扫描。
5. 所有关键数据必须标注：来源名称、数据日期/发布时间、抓取时间、字段口径。
6. 对无法获取的数据，明确写“数据缺失”，并降低置信度或推荐优先级；严禁用经验值、旧记忆或主观猜测补全。
7. 若同一指标多源冲突，优先官方、交易所、上市公司公告、权威行情源，并在页面底部披露“数据口径存在差异”。

### 3. 数据源优先级

| 类型 | 优先来源 | 备用来源 | 必须说明 |
|:---|:---|:---|:---|
| 行情/指数/ETF | Wind/iFind/XTick/Tushare/交易所 | AkShare/东方财富/同花顺/新浪/腾讯 | 最新交易日、复权/不复权口径 |

|:---|:---|:---|

### 背离优先级

1. 资金高 + 情绪低：聪明钱逆势布局，重点观察右侧确认。
2. 资金低 + 情绪高：散户追高或主力兑现，风险优先。
3. 动量高 + 宽度低：指数抱团，持续性存疑。
4. 综合低位 + 政策利多：可能出现政策底，但必须等待资金确认。

## 当前任务
请对今日A股大盘量化因子数据进行多维度交叉分析，核心目标是判断当前市场处于「冰点-沸点」区间中的哪个位置，以及四因子之间是否存在背离或共振信号。

## 分析框架

### 1. 均线位置分析
- 当前指数与5日均线、20日均线的位置关系：
  * 指数在5日线上方 = 短期强势；下方 = 短期承压
  * 指数在20日线上方 = 中期多头；下方 = 中期转弱
  * 5日与20日均线的方向关系（双线上行/交叉/双线下行）
- 计算乖离率（偏离均线的百分比），判断超买超卖程度
- 关注5日和20日均线是否即将发生金叉/死叉

### 2. 四因子联动分析（核心）
必须分析四个量化因子之间的联动关系，重点识别以下信号：

**【背离信号 — 最具分析价值】**
- 资金高 + 情绪低 = 「聪明钱逆势布局」，机构在散户恐惧时吸筹
- 资金低 + 情绪高 = 「散户追高、主力出货」，诱多风险
- 动量高 + 情绪低 = 「无量空涨」，动能不可持续
- 动量低 + 资金高 = 「底部蓄力」，方向选择在即

**【共振信号 — 趋势确认】**
- 动量+情绪+资金三高 = 「多头共振」，趋势加速
- 动量+情绪+资金三低 = 「空头共振」，需防御
- 指数站上双均线 + 三因子齐升 = 「右侧确认」

### 3. 综合因子区间定位
- 综合因子当前值在0-100分制中的位置（冰点<20 / 低迷20-40 / 中性40-60 / 活跃60-80 / 沸点>80）
- 综合因子趋势方向（对比近期走势，判断是上行/下行/横盘）
- 当前区间历史胜率参考（该区间下大盘后续5日上涨概率）

### 4. 事件与政策维度（联网搜索）
- 必须联网搜索今日最新宏观政策、重大会议、监管动态
- 将政策面信息与因子数据进行匹配验证：
  * 情绪因子低但政策面有重磅利好 → 情绪可能被反转，关注「政策底」信号
  * 资金因子高 + 政策持续加码 → 增量逻辑确认
  * 综合因子中性但外部风险事件发酵 → 警惕向下破位

## 预期差判断标准

- 「超预期」：因子信号明显强于政策面/消息面支撑，有未被市场充分认知的增量逻辑
- 「符合预期」：因子信号与已知信息面基本吻合，市场处于合理定价区间
- 「不及预期」：因子信号弱于政策面/消息面应有表现，存在隐忧未被消化
