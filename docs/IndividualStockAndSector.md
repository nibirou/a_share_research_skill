## 二、原模板不足与本版优化方向

### 1. 原模板不足

原模板依赖用户手动提供某一板块及其 Top20 个股资金数据，存在以下问题：

* **数据覆盖不完整**：只能分析用户给定板块，无法发现全市场真正最强主线。
* **样本存在偏差**：Top20 个股来自用户输入，可能遗漏真实资金龙头或高弹性标的。
* **实时性不足**：用户提供的数据可能滞后，无法反映最新资金切换。
* **行业归属被动**：无法主动比较申万行业、同花顺行业、东方财富概念等多套分类体系。
* **交叉概念判断容易主观化**：若不联网验证，容易凭经验推断热点逻辑。
* **财务与公告验证不足**：仅靠资金数据容易误判 ST、亏损股、概念炒作股。

### 2. 本版优化目标

本提示词要求 AI 不再依赖用户上传板块和个股数据，而是：

* 自主联网获取 A 股全市场行业、概念、成分股、资金流、财务、公告、政策、研报、产业数据。
* 基于申万行业、同花顺行业、同花顺概念、东方财富概念等分类体系，全量扫描所有板块与概念。
* 对所有板块 / 概念进行横向比较，自动筛选当前资金强度、持续性、产业催化和基本面匹配度最高的主线。
* 对最终筛选出的目标板块 / 概念内所有成分股逐一分析，不得只分析资金流入股。
* 所有数据必须标注来源、时间、口径；无法获取的数据必须标记为“数据缺失”，不得虚构。

## 七、资金数据口径

### 1. 优先口径：超资数据

若数据源能直接获取以下字段，优先使用：

* 超资入场 3D
* 超资抢筹 5D
* 超资控盘 20D

字段含义：

| 字段       | 含义                 |
| -------- | ------------------ |
| 超资入场 3D  | 最近 3 个交易日超额资金净流入强度 |
| 超资抢筹 5D  | 最近 5 个交易日主力资金抢筹强度  |
| 超资控盘 20D | 最近 20 个交易日中期资金控盘强度 |

### 2. 替代口径：资金流代理指标

若无法直接获取“超资”字段，则必须使用可验证代理指标：

```text
3D 超资代理 = 最近 3 个交易日主力净流入额合计 / 最新流通市值 × 100%
5D 超资代理 = 最近 5 个交易日主力净流入额合计 / 最新流通市值 × 100%
20D 超资代理 = 最近 20 个交易日主力净流入额合计 / 最新流通市值 × 100%
```

要求：

* 必须在页面中注明“超资数据为代理口径”。
* 主力净流入额必须来自公开行情或资金流数据源。
* 流通市值必须使用最新交易日数据。
* 若主力净流入额缺失，可使用大单净流入额作为二级代理，但必须标注。

### 3. 板块资金指标

板块资金强度计算：

```text
板块 3D 资金强度 = 板块内所有成分股 3D 主力净流入额合计 / 板块总流通市值 × 100%
板块 5D 资金强度 = 板块内所有成分股 5D 主力净流入额合计 / 板块总流通市值 × 100%
板块 20D 资金强度 = 板块内所有成分股 20D 主力净流入额合计 / 板块总流通市值 × 100%
资金净流入家数占比 = 板块内 3D 资金为正股票数 / 板块总股票数
三周期全正占比 = 3D、5D、20D 全正股票数 / 板块总股票数
```

根据资金状态打标签：

生成 HTML 前必须自查：

* 是否已经全市场扫描行业和概念？
* 是否展示了全市场 Top10 板块 / 概念评分表？
* 是否自动选择了目标板块？
* 是否获取了目标板块全部成分股？
* 是否逐一分析了所有成分股？
* 是否标注了 ST / *ST 风险？
* 是否排除了 ST / *ST 推荐？
* 是否给出 3-5 只精选标的？
* 是否包含 6 个月路线图？
* 是否说明数据来源和资金口径？
* 是否使用 Chart.js CDN？
* 是否为完整 HTML？
* 是否没有输出 Markdown？
* 是否没有编造数据？

---

## 二十一、最终输出格式

最终只能输出以下形式：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  ...
</head>
<body>
  ...
</body>
</html>
```

不得在 HTML 前后添加任何解释性文字。
